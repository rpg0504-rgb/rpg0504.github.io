# 斧犬夜班：繃帶醫院 — 遊戲設計文件

以院區一樓平面圖為基礎的俯視動作遊戲。單一 `index.html`，無外部相依，開啟即玩。

- 線上遊玩：合併後於 GitHub Pages 的 `/axe-dog/`
- 本機遊玩：直接用瀏覽器開 `index.html`

---

## 1. 概念

| 項目 | 設定 |
| --- | --- |
| 主角 | 院區警衛犬「阿斧」——四條腿走路、背心、一把消防斧 |
| 世界觀 | 凌晨三點，醫院被「痛覺病毒」吞沒，病患化為會走路的繃帶惡夢 |
| 敵人 | 繃帶怪物（明確非寫實：被擊倒時炸成繃帶碎片與星星，無血腥表現）|
| 核心循環 | 進房 → 遭遇未知數量的敵人 → 清空 → 拿補給與武器 → 下一間 |
| 目標 | 清空全部 36 間房，搭訪客電梯上二樓；集滿三張門禁卡可從大門提前撤離 |
| 類型 | 俯視角動作 / 清版探索，單場約 20–35 分鐘 |

## 2. 房間規則

這是整個設計的骨幹：

- **敵人被關在自己的房間裡。** 每隻敵人綁定一個 `home` 房間，每幀位置都會夾回房間矩形內，追不到走廊。走廊是安全的移動空間。
- **只有玩家進到同一間，敵人才會甦醒。** 玩家離開房間，房裡的敵人立刻停止追擊、改成原地閒晃。
- **進門前不知道裡面有幾隻。** 未探索的房間在畫面與小地圖上都蓋著迷霧並標示 `?`，房裡的敵人不會被繪製。踏進門的瞬間才揭示「敵人 ×N」。
- **敵人的遠程攻擊也出不了房間**——飛出 `home` 房間範圍的子彈會消失。
- **清空 → 獎勵。** 房裡最後一隻倒下時，房間中央掉出骨頭（回 24 HP）＋一件武器或一份彈藥；每清滿 4 間額外掉一個強化模組。

## 3. 武器

| 武器 | 取得 | 傷害 | 冷卻 | 彈藥上限 | 特性 |
| --- | --- | --- | --- | --- | --- |
| 消防斧 | 初始 | 22 | 0.38s | ∞ | 扇形近戰，範圍 66px、±0.85 rad，有連擊加成 |
| 手槍 | 清空**維康便利** | 17 | 0.20s | 120 | 單發快射 |
| 散彈槍 | 清空**放射科A區** | 11 ×7 發 | 0.60s | 60 | 扇形 0.46 rad，近距爆發，有後座力 |
| 水球 | 清空**醫學美容中心** | 24＋濺射 74px | 0.46s | 80 | 命中後讓範圍內敵人減速 2.6 秒 |
| 大炮 | 清空 **MRI**（頭目房） | 72＋濺射 104px | 1.00s | 30 | 大範圍爆炸，強力擊退，後座力明顯 |

- 切換：數字鍵 `1`–`5`、`Q` 循環、滑鼠滾輪；手機按右下「換」鈕。
- **升級**：撿到強化模組會把當前武器升一級，最高 Lv3。Lv2 傷害 ×1.35、射速 ×0.85；Lv3 傷害 ×1.75、射速 ×0.72。滿級後改為補彈藥。
- 彈藥歸零會自動切回還有子彈的武器（最後退回斧頭）。
- 已擁有的武器再次從房間掉出時改為該武器的彈藥補給。

## 4. 視角切換

按 `V`（手機按右下「3D」鈕）在**平面圖**與**立體視角**之間切換，遊戲邏輯完全不變，只換投影：

- 等角投影 `sx = (x−y)·0.72`、`sy = (x+y)·0.42`，牆體往上擠出 46px 的立方體。
- 立體圖層在第一次切換時才建（約 1.2 秒，畫面會顯示「建立立體視圖⋯」），之後快取重用。
- 牆體由後往前依 `cx+cy` 排序疊繪；角色為看板式精靈，朝向經過投影換算，滑鼠瞄準走反投影。

## 7. 操作

**鍵盤**：`WASD`／方向鍵移動、滑鼠瞄準、左鍵或空白鍵攻擊、`Shift` 翻滾（無敵幀）、`1`–`5`／`Q`／滾輪換武器、`V` 切視角、`P` 暫停、`R` 重來。
以 `e.code`（實體按鍵位置）判定，注音等輸入法開著也能動。

**觸控**：左半邊拖曳為虛擬搖桿（類比速度），右下四顆鈕為攻擊／翻滾／換武器／切視角。觸控沒有滑鼠可瞄準，改為自動朝 260px 內最近的敵人。

## 8. 技術

| 系統 | 作法 |
| --- | --- |
| 樓層 | `FLOORS` 陣列，每層各自建網格、流場、平面圖與立體圖層；`useFloor(n)` 整批切換 |
| 地圖 | 矩形集合 → 10px 網格；牆是可行走區的補集 |
| 碰撞 | 圓 vs 格子 AABB，分軸解算（可沿牆滑行）|
| 尋路 | BFS 流場，每 0.18s 或玩家換格時重算，全體敵人共用 |
| 房間約束 | 每幀把敵人座標夾回 `home` 房間矩形（`confine()`）|
| 繪圖 | 平面／立體地圖各預繪一張離螢幕 canvas，每幀只貼圖；小地圖是平面圖的縮圖 |
| 角色 | 全部用 canvas 向量繪製，無圖檔相依 |
| 音效 | WebAudio 即時合成 |
| 效能 | 86 隻敵人、兩種視角下實測約 60 FPS |

## 9. 除錯／改造

主控台的 `AXEDOG` 提供 `G`、`P`、`FLOORS`、`FL`、`ROOMS`、`WEAPONS`、`useFloor()`、`goFloor()`、`toggleView()`、`populate()`：

```js
AXEDOG.P.owned.cannon = true; AXEDOG.P.ammo.cannon = 99   // 直接拿大炮
AXEDOG.P.lv.shotgun = 3                                    // 散彈槍升到滿級
AXEDOG.G.liftOpen = true; AXEDOG.goFloor(1)                // 直接上二樓
AXEDOG.toggleView()                                        // 切立體視角
AXEDOG.ROOMS.forEach(r => r.seen = true)                   // 掀開全部迷霧
```

**新增房間**：在該樓層的 `rooms` 加一筆 `{id, name, x, y, w, h, c, doors}`，房間之間至少留 20px 間隙當牆，`doors` 用 `D(邊, 位移, 寬度)` 打通到相鄰走廊，再到 `SPAWN_TABLE` 補上敵人配置。
**新增武器**：在 `WEAPONS` 加一筆並列進 `WEAPON_ORDER`，指定掉落房間寫進 `WEAPON_ROOMS`。
