# 斧犬夜班：繃帶醫院 — 遊戲設計文件

以院區一樓平面圖為基礎的俯視動作遊戲。單一 `index.html`，無外部相依，開啟即玩。

- 線上遊玩：合併後於 GitHub Pages 的 `/axe-dog/`
- 本機遊玩：直接用瀏覽器開 `index.html`

---

| 項目 | 設定 |
| --- | --- |
| 主角 | 院區警衛犬「阿斧」——四條腿走路、背心、一把消防斧 |

## 2. 房間規則

這是整個設計的骨幹：

- **敵人被關在自己的房間裡。** 每隻敵人綁定一個 `home` 房間，每幀位置都會夾回房間矩形內，追不到走廊。走廊是安全的移動空間。
- **只有玩家進到同一間，敵人才會甦醒。** 玩家離開房間，房裡的敵人立刻停止追擊、改成原地閒晃。
- **進門前不知道裡面有幾隻。** 未探索的房間在畫面與小地圖上都蓋著迷霧並標示 `?`，房裡的敵人不會被繪製。踏進門的瞬間才揭示「敵人 ×N」。
- **敵人的遠程攻擊也出不了房間**——飛出 `home` 房間範圍的子彈會消失。
- **站門口打不到裡面。** 攻擊只對「玩家目前所在房間」的敵人有效；子彈飛到門檻就消失。想打就得進去。
- **清空 → 獎勵。** 房裡最後一隻倒下時掉出骨頭（回 24 HP）＋一件武器或一份彈藥，外加一筆 🤑 錢；每清滿 4 間額外掉一個強化模組。

## 2b. 金錢 🤑

| 來源 | 金額 |
| --- | --- |
| 擊倒一般敵人 | 6＋階級×4 |

## 2c. 武器階級（秒殺規則）

每把武器有階級 T1–T3，每隻怪物的階級等於牠所在的樓層。

| 武器階級 − 怪物階級 | 效果 |
| --- | --- |
| ≥ +1 | **秒殺**（頭目免疫，改為 1.6 倍傷害）|
| 0 | 正常傷害 |
| −1 | 傷害 32% |
| ≤ −2 | 傷害 14% |

也就是說：**高樓層的武器可以秒殺低樓層的怪物**，而怪物每上一層就變強（HP ×(1+1.25×(階級−1))、傷害 ×(1+0.6×(階級−1))、移速 ×(1+0.12×(階級−1))），舊武器很快就打不動。HUD 會直接標示目前武器對這間房是「越級 — 可以秒殺」還是「階級不足 — 傷害剩 32%」。

### 傳說武器（成就解鎖）

**每累積 3 個成就送一把**，共三把：除顫電弧（連鎖閃電）、骨鋸旋風（270° 近戰）、黑洞彈。

- 切換：數字鍵 `1`–`5`、`Q` 循環、滑鼠滾輪；手機按右下「換」鈕。
- **升級**：撿到強化模組會把當前武器升一級，最高 Lv3。Lv2 傷害 ×1.35、射速 ×0.85；Lv3 傷害 ×1.75、射速 ×0.72。滿級後改為補彈藥。
- 彈藥歸零會自動切回還有子彈的武器（最後退回斧頭）。
- 已擁有的武器再次從房間掉出時改為該武器的彈藥補給。

## 3b. 紀錄與成就

紀錄存在瀏覽器的 `localStorage`（鍵名 `axedog.v3`），換裝置不會同步。

- **進度存檔**：每次清空房間或換樓層自動存檔。標題畫面出現「繼續上次進度」按鈕。
  讀檔採檢查點模式——**已清空的房間維持清空，未清空的房間重新佈敵**，武器、等級、彈藥、錢、門禁卡都會還原。
- **最佳紀錄**：最多清空房間、最高金錢、最多擊倒、抵達最高樓層、最快通關、遊玩／通關次數、擊敗大魔王次數。
- **成就**：共 14 個，標題畫面以標籤列出。

| 成就 | 條件 |
| --- | --- |
| 初次見血 / 開張 | 第一次擊倒 / 第一次清房 |
| 毫髮無傷 | 不掉血清空一整間房 |
| 一發三殺 | 一次爆炸解決三隻 |
| 頭目獵人 / 全門禁 | 擊倒任一頭目 / 集滿三張門禁卡 |
| 發財了 🤑 | 身上錢超過 1000 |
| 清潔隊 / 一樓淨空 | 清空 10 間 / 清空一樓全部 |
| 黑手 | 組合出第一把武器 |
| 登上二樓 / 十連擊 | 抵達二樓 / 達成 10 連擊 |
| 越級打怪 | 用高階武器秒殺一隻怪 |
| 送走死神 💀 | 擊敗大魔王 |

## 4. 視角切換

按 `V`（手機按右下「3D」鈕）在**平面圖**與**立體視角**之間切換，遊戲邏輯完全不變，只換投影：

- 等角投影 `sx = (x−y)·0.72`、`sy = (x+y)·0.42`，牆體往上擠出 46px 的立方體。
- 立體圖層在第一次切換時才建（約 1.2 秒，畫面會顯示「建立立體視圖⋯」），之後快取重用。
- 牆體由後往前依 `cx+cy` 排序疊繪；角色為看板式精靈，朝向經過投影換算，滑鼠瞄準走反投影。

## 5. 樓層

| 樓層 | 階級 | 內容 |
| --- | --- | --- |
| 一樓 | T1 | 36 間房、11 條走廊、3 處出入口，依平面圖建置 |
| 二樓 | T2 | 手術室、加護病房、產房、病房區、訪客電梯，＋**頂層手術房（大魔王）** |

- 一樓 36 間全部清空後，訪客電梯啟動（畫面與小地圖有光圈提示），走進去上樓；二樓的訪客電梯可以下樓。
- 二樓的怪物是 T2，一樓拿的 T1 武器傷害只剩 32%——得先在二樓拿到雷射槍或冷凍槍，或者先組合出 T2／T3 武器。
- **頂層手術房的門是封印的**，清空二樓其他四間房才會解開。封印會實際擋住玩家移動並跳出提示。

| 階段 | 觸發 | 招式 |

| 一 | HP > 66% | 12 向鐮刀環狀彈幕 |

## 7. 操作

**鍵盤**：`WASD`／方向鍵移動、滑鼠瞄準、左鍵或空白鍵攻擊、`Shift` 翻滾（無敵幀）、`1`–`5`／`Q`／滾輪換武器、`V` 切視角、`P` 暫停、`R` 重來。
以 `e.code`（實體按鍵位置）判定，注音等輸入法開著也能動。

**觸控**：左半邊拖曳為虛擬搖桿（類比速度），右下四顆鈕為攻擊／翻滾／換武器／切視角。觸控沒有滑鼠可瞄準，改為自動朝 260px 內最近的敵人。

## 8. 技術

| 系統 | 作法 |
| --- | --- |
| 紀錄 | `localStorage` 單一鍵值，存成就、傳說武器發放數、最佳紀錄與進度存檔；讀寫都包 try/catch |
| 門檻規則 | 近戰略過 `e.home !== G.curRoom` 的敵人；子彈在 `roomAt()` 變化時於門檻消散 |
| 封印門 | `G.seals` 記錄門的矩形，只對玩家做碰撞檢查（`sealBlocks`），清空同層其他房後解除 |
| 樓層 | `FLOORS` 陣列，每層各自建網格、流場、平面圖與立體圖層；`useFloor(n)` 整批切換 |
| 地圖 | 矩形集合 → 10px 網格；牆是可行走區的補集 |
| 碰撞 | 圓 vs 格子 AABB，分軸解算（可沿牆滑行）|
| 尋路 | BFS 流場，每 0.18s 或玩家換格時重算，全體敵人共用 |
| 房間約束 | 每幀把敵人座標夾回 `home` 房間矩形（`confine()`）|
| 繪圖 | 平面／立體地圖各預繪一張離螢幕 canvas，每幀只貼圖；小地圖是平面圖的縮圖 |
| 角色 | 全部用 canvas 向量繪製，無圖檔相依 |
| 音效 | WebAudio 即時合成 |
| 效能 | 86 隻敵人、兩種視角下實測約 60 FPS |

## 9. 除錯／改造

主控台的 `AXEDOG` 提供 `G`、`P`、`FLOORS`、`FL`、`ROOMS`、`WEAPONS`、`RECIPES`、`ACHIEVEMENTS`、`STORE`，以及 `useFloor()`、`goFloor()`、`toggleView()`、`populate()`、`autoSave()`、`unlockAch()`、`doCombine()`、`resetStore()`：

```js
AXEDOG.P.money = 9999                                      // 給錢
AXEDOG.P.owned.laser = true; AXEDOG.P.ammo.laser = 200     // 直接拿二樓武器
AXEDOG.P.lv.shotgun = 3                                    // 散彈槍升到滿級
AXEDOG.G.liftOpen = true; AXEDOG.goFloor(1)                // 直接上二樓
AXEDOG.ROOMS.find(r => r.id === 'chief').locked = false    // 解開大魔王的封印
AXEDOG.unlockAch('reaper')                                 // 手動解鎖成就
AXEDOG.resetStore()                                        // 清掉所有紀錄與存檔
```

**新增房間**：在該樓層的 `rooms` 加一筆 `{id, name, x, y, w, h, c, doors}`，房間之間至少留 20px 間隙當牆，`doors` 用 `D(邊, 位移, 寬度)` 打通到相鄰走廊，再到 `SPAWN_TABLE` 補上敵人配置。
**新增武器**：在 `WEAPONS` 加一筆（記得給 `tier`）並列進 `WEAPON_ORDER`，指定掉落房間寫進 `WEAPON_ROOMS`。
**新增配方**：在 `RECIPES` 加 `{a, b, out, cost}`。
**新增成就**：在 `ACHIEVEMENTS` 加一筆，在對應的地方呼叫 `unlockAch('id')`。
**新增樓層**：在 `FLOORS` 加一筆（含 `tier`），佈敵表放進 `populate()`，用 `lift:'up'/'down'` 串電梯。
