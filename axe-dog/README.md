# 斧犬夜班：繃帶醫院 — 遊戲設計文件

以院區一樓平面圖為基礎的俯視動作遊戲。單一 `index.html`，無外部相依，開啟即玩。

- 線上遊玩：`https://rpg0504.github.io/axe-dog/`
- 本機遊玩：直接用瀏覽器開 `index.html`

---

## 2. 空間設計：平面圖如何變成關卡

平面圖直接當成關卡佈局，世界座標 1400 × 1970，格子 10px。
**走廊是負空間**——先鋪可行走的矩形（走廊、房間、門），其餘自動變成牆，
所以整張圖的動線骨架跟原圖一致。

| 代號 | 位置 | 對應原圖 |

| `CH6` | 橫貫全院，y=1100 | 主通道：**大門 ↔ 南側門** |
| `CV0` / `CV6` | 西/東側縱向主幹 | 西側動線、南側門動線 |

## 3. 系統

### 玩家
| 數值 | 值 |
| --- | --- |
| HP | 100 |
| 移速 | 200 /s（咖啡因 ×1.35，揮斧中 ×0.55）|
| 斧頭傷害 | 22 + 連擊數 × 1.2（磨刀石 ×1.6）|
| 揮擊 | 範圍 66px、扇形 ±0.85 rad、冷卻 0.38s |
| 翻滾 | Shift，0.17s／速度 560、冷卻 0.75s、**期間無敵** |

操作支援鍵盤與觸控兩套：

- **鍵盤**：以 `e.code`（實體按鍵位置）判定，注音等輸入法開著時照樣能動；同時保留 `e.key` 作為舊瀏覽器的退路。
- **觸控**：左半邊拖曳為虛擬搖桿（類比速度），右下兩顆鈕為揮斧與翻滾。觸控沒有滑鼠可瞄準，改為自動朝 240px 內最近的敵人，沒有敵人時面向移動方向。
- 以 `matchMedia('(pointer: coarse)')` 判斷是否預設顯示觸控介面；小畫面時血條移到左上、小地圖縮到畫面寬的 32%，避免和操作鈕重疊。
| 連擊 | 2.2 秒內連續擊殺累積，斷了歸零 |

## 4. 技術

| 系統 | 作法 |
| --- | --- |
| 地圖 | 矩形集合 → 10px 網格；牆是可行走區的補集 |
| 碰撞 | 圓 vs 格子 AABB，分軸解算（可沿牆滑行）|
| 尋路 | BFS 流場，每 0.18s 或玩家換格時重算一次，全體敵人共用 |
| 視線 | 對網格取樣的線段測試，決定敵人是否甦醒／開火 |
| 繪圖 | 靜態地圖預繪到離螢幕 canvas，每幀只貼圖；小地圖是同一張圖的縮圖 |
| 角色 | 全部用 canvas 向量繪製，無圖檔相依 |
| 音效 | WebAudio 即時合成 |
| 效能 | 95 個敵人下實測 ~60 FPS |

## 5. 除錯／改造

開瀏覽器主控台，`AXEDOG` 提供 `G`（遊戲狀態）、`P`（玩家）、`ROOMS`、`ETYPES`、`BOSSES`、`map`、`respawn()`：

```js
AXEDOG.P.sp = 400          // 玩家變快
AXEDOG.P.hp = 999          // 補血
AXEDOG.G.enemies.length=0  // 清場
AXEDOG.respawn()           // 重新佈署敵人
```

新增房間：在 `ROOMS` 加一筆 `{id, name, x, y, w, h, c, doors}`，
房間之間至少留 20px 間隙當牆，`doors` 用 `D(邊, 位移, 寬度)` 打通到相鄰走廊；
再到 `populate()` 的 `tables` 補上該房間的敵人配置即可。
